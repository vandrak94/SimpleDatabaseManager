# Simple Database Manager

Desktopová aplikace pro práci s databázemi SQLite 3 (`.db`, `.sqlite`, `.sqlite3`).

- Výběr existující databáze při spuštění; zrušení výběru ukončí aplikaci.
- Přidávání, přejmenování a mazání tabulek.
- Zobrazení, přidávání, úpravy a mazání záznamů.
- Chybový log `SimpleDatabaseManager.log` vedle spouštěcího souboru.

Pro vytvoření přenosné Windows aplikace spusťte `build-exe.bat` (JDK 17+).
Před úpravami databáze doporučujeme zálohu.
